# Fragmented libledger89

Strict C89 syntax; POSIX file API; dependencies libappend89.
Single public essentials header. No protocol types, checksum, index, manifest,
rotation, replication, or exact stable frontier. Specification is normative.
Do not confuse this implementation with exploratory/libledger89 (legacy v2);
their public symbols overlap and they must not be linked together.
Changes follow scenario -> failing test -> implementation -> verification.
Four spaces, Allman braces. Do not commit or push without explicit permission.
